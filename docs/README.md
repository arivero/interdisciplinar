# Published Papers

This folder contains HTML versions of all research papers, published via GitHub Pages.

## Papers Included

### Main Review
- **main.html** - Main review manuscript on interdisciplinarity measurement

### Satellite Papers (English)
- **sat1-institutional.html** - Measuring Interdisciplinarity with Internal University Data: An Operational Guide
- **sat2-national-evaluation.html** - Incorporating Interdisciplinarity Indicators into National Research Evaluation Frameworks

### Satellite Papers (Spanish)
- **main-review-es.html** - Medición de la Interdisciplinariedad: Un Panel de Indicadores Multicomponente
- **sat1-institutional-es.html** - Medición de Interdisciplinariedad con Datos Internos Universitarios: Guía Operacional
- **sat2-national-evaluation-es.html** - Incorporación de Indicadores de Interdisciplinariedad en Marcos de Evaluación Nacional

## Accessing the Papers

Once GitHub Pages is enabled, these papers are accessible at:
https://arivero.github.io/interdisciplinar

## Source Files

The source Markdown files for these papers are located in:
- `/paper/main.md` - Main review manuscript
- `/papers/*/main.md` - Satellite papers

HTML files are generated from Markdown using pandoc. See the repository README for build instructions.

## Jekyll Configuration

The `_config.yml` file contains GitHub Pages/Jekyll configuration settings for the published site.
