# C20 Debate: How aggressive should Spanish edits be?

Date: 2026-02-15

## Question
Should the Spanish pass rewrite sentences for style, or restrict itself to minimal grammar fixes to avoid meaning drift?

## Options
1. Minimal grammar-only edits (safer).
2. Broader stylistic rewrites where Spanish sounds unnatural (riskier).

## Decision
Option 1.

## Rationale
English is the source of truth; this pass should improve Spanish correctness without altering technical meaning.

## Consequences / Follow-ups
- If readability still feels stiff after grammar fixes, run a separate dedicated style pass later.
