# S04 Plan: Institutional Measurement Witness Scenario

Date: 2026-02-15

## Goal
Design a concrete institutional measurement scenario that demonstrates how
universities with full internal data access can compute and deploy the
indicator panel. This supports Satellite 1 (institutional measurement).

## Context
D04 identified:
- Δ and S computable from institutional repository data + similarity matrix
- E requires external citation data (main obstacle)
- Additional institutional-only indicators: co-authorship diversity,
  co-supervision diversity, grant diversity

Satellite 1 target: operational measurement recipe for universities

## Approach
Create a witness scenario in blackboards/3.md with:
1. Mock institutional data (publications, co-authorships, PhD supervisions, grants)
2. Panel computation from internal data
3. Gap analysis (what requires external data)
4. Additional institutional-only indicators computed
5. Comparison: what bibliometric-only vs. institution-enriched panels reveal

## Success criteria
- Complete blackboard/3.md with institutional measurement scenario
- All computations use realistic mock data
- Clear mapping of data → indicators
