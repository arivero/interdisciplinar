# B01 Debate: Recency vs Canonical Foundations

Date: 2026-02-15

## Question
How much should B01 prioritize very recent sources versus canonical indicator papers?

## Decision
Use a mixed strategy: preserve canonical anchors, but prioritize recent sources when
they refine, validate, or challenge canonical indicator claims.

## Rationale
The project goal is an accurate state-of-knowledge report, which requires both
historical grounding and current evidence.
