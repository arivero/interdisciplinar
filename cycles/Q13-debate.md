# Q13 Debate: Decimal Conventions in Spanish Manuscripts

Date: 2026-02-15

## Question
Should `paper/main.es.md` use decimal comma consistently (Spanish convention), even inside math mode,
or preserve decimal dot to match the English manuscript and typical technical typesetting?

## Current resolution
Prefer internal consistency over language purity:
- If using decimal comma, apply it consistently in narrative and tables, and avoid mixing.
- Keep dot where values are explicitly copied from an English-derived computation block, unless
  a deliberate Spanish-facing normalization is performed everywhere.
