# S00 Debate: Include Budget/Staff Inputs in First Witness?

Date: 2026-02-15

## Question
Should the first technical witness already include budget/staff variables, or start with
bibliometric-only inputs and extend later?

## Decision
Start bibliometric-only in S00; add budget/staff in a follow-up S cycle.

## Rationale
A smaller first witness reduces implementation risk and clarifies core indicator behavior
before introducing institutional confounders.

## Addendum: 2026-02-15 — Post-Computation Reflection

### Supplementary question
Is the cross-field effect proxy E redundant with Δ?

### Resolution
No. E measures downstream impact (who cites the work), while Δ measures upstream composition (what the work references). A polymath could have high Δ but near-zero E, confirming the orthogonality. The toy data demonstrates: Δ_A ≈ Δ_B but E_A ≫ E_B.
