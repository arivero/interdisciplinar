# S02 Debate: Fixed Thresholds vs Relative Ranking?

Date: 2026-02-15

## Question
Should the evaluation protocol use fixed thresholds (Δ ≥ 0.40 for integrator)
or rank researchers relative to a reference distribution?

## Current position
Fixed thresholds for the toy computation, with explicit acknowledgment that real
deployment requires calibration against empirical distributions. The thresholds
are a starting point, not a final prescription.

## What would change my mind?
- If empirical distributions of (Δ, S, E) across actual "Interdisciplinar" researchers
  show that the proposed thresholds misclassify > 20% of cases, relative ranking
  would be preferable.
- If field-specific citation norms make E incomparable across disciplines without
  normalization, fixed thresholds on E are invalid.
