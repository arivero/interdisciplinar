# C21 Debate: Spanish terminology consistency

Date: 2026-02-15

## Question
How should we handle terminology in Spanish when the English uses technical terms with multiple plausible translations (e.g., "polymath", "journal-based assignment")?

## Options
1. Keep existing Spanish terminology unless clearly wrong; fix only grammar.
2. Normalize terminology across the whole Spanish paper to a chosen glossary.

## Decision
Option 1 with targeted normalization only where the Spanish currently misrepresents English meaning.

## Rationale
Terminology changes can cause subtle meaning drift; prioritize faithfulness to the English source of truth.
