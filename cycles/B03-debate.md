# B03 Debate: How Far Back Should Source Mining Go?

Date: 2026-02-15

## Question
Should we add pre-2020 papers found in reference mining to the bibliography?

## Current position
Not yet. The critical gap was post-2020 coverage, which is now addressed (8 new keys).
Pre-2020 candidates (Zhang 2016, Wang-Thijs-Glänzel 2015, Hicks 2015 Leiden Manifesto,
Mugabushaka 2016 Leinster-Cobbold) should be evaluated during D02 (indicator taxonomy)
to determine which are actually needed for the review structure.
