# C27 Red Team: Formula cheatsheet and LaTeX sheet

Date: 2026-02-15

## Failure modes
- Overclaiming / scope creep:
  - Mitigation: limit to formulas already defined in `paper/main.md`; no new indicators or derivations.
- Missing derivation / fragile step:
  - Mitigation: ensure each entry cites its manuscript section so readers can check full context.
- Weak anchoring (load-bearing claim without independent support):
  - Mitigation: keep descriptions minimal and descriptive rather than interpretive; defer any new claims.
- Reader confusion (notation, dimension, conventions):
  - Mitigation: use the same notation as the manuscript and include one-line cues for meaning.
