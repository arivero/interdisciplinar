# Formula Extractions from New Sources (2020-2025)

## Source: Hill 1973 (Ecology)

### Hill Numbers (Diversity of Order a)
**Symbol**: Na
**Type**: Diversity
**Formula**: `Na = (p1^a + p2^a + ... + pn^a)^(1/(1-a))`
**Variables**:
- pi = proportional abundance of species i
- a = order parameter
- n = total number of species

**Notes**: Unifying framework for diversity measures. N0 = total species richness, N1 = exp(Shannon entropy), N2 = 1/Simpson index. Na is monotonically decreasing in a. Reciprocal of (a-1)th root of weighted mean of (a-1)th powers of proportional abundances.

### Hill Number N1 (Exponential Shannon)
**Symbol**: N1
**Type**: Diversity
**Formula**: `N1 = exp(-Σ pi ln(pi)) = exp(H)`
**Variables**:
- H = Shannon entropy
- pi = proportional abundances

**Notes**: Limiting case as a→1. Geometric mean of proportional abundances (weighted by themselves). Intermediate between N0 and N2.

### Hill Number N2 (Inverse Simpson)
**Symbol**: N2
**Type**: Diversity
**Formula**: `N2 = 1/(p1² + p2² + ... + pn²)`
**Notes**: Reciprocal of Simpson index. Arithmetic mean of proportional abundances.

### Evenness
**Symbol**: Ea,b
**Type**: Evenness
**Formula**: `Ea,b = Na/Nb`
**Variables**:
- Na, Nb = diversity numbers of orders a and b

**Notes**: Ratio of two diversity numbers. E1,0 = exp(H)/n. When all species equally abundant, Ea,b = 1 for all a,b. Satisfies "doubling criterion": merging species with doubles preserves evenness.

### Alternative Evenness
**Symbol**: J'
**Type**: Evenness
**Formula**: `J' = ln(N1)/ln(N0) = H/Hmax`
**Notes**: Standard Pielou evenness. Does NOT satisfy doubling criterion. Hill shows mediant-based measures Ea,b are superior.


## Source: Jost 2006 (Oikos)

### True Diversity (Numbers Equivalent)
**Symbol**: qD or Nq
**Type**: Diversity
**Formula**: `qD = (Σ pi^q)^(1/(1-q))`
**Variables**:
- q = order parameter
- pi = proportions

**Notes**: Numbers equivalent of generalized entropy. When q=0: species richness. When q=1: exp(Shannon). When q=2: inverse Simpson. All generalized entropies of same order have identical numbers equivalents.

### Conversion from Entropy to Diversity
**Symbol**: qD
**Type**: Diversity
**Formula**: `qD = exp(Hq)` where `Hq = (1/(1-q)) ln(Σ pi^q)`
**Notes**: Entropies must be converted to effective numbers before interpretation as diversity. Exponential relationship ensures proper doubling behavior.


## Source: Jost 2009 (Ecological Economics)

### Replication Principle
**Statement**: If N communities have identical species abundances but no shared species, diversity of pooled communities = N × D(p)
**Formula**: `D(pooled) = N · D(single community)`
**Notes**: Essential property for valid diversity measures. Only satisfied by numbers equivalents (Hill numbers), not by raw entropies.

### Partitioning Property
**Statement**: For complete partitioning, within-group diversity × between-group diversity = total diversity
**Formula**: `Nq(within) × Nq(between) = Nq(total)`
**Notes**: Multiplicative partitioning. Valid for all orders q when partitioning is complete. Does NOT hold for raw entropies.

**Note**: Biodiversity ecology paper. Relevant for validation of Hill numbers framework but no new IDR-specific formulas.


## Source: Goyanes 2020 (Scientometrics)

### Pattern Diversity Score
**Symbol**: PD
**Type**: Diversity (multidimensional)
**Formula**: Based on multivariate analysis combining variety, balance, disparity
**Notes**: Operationalized for communication research using author affiliations, methods, theories. No single closed-form formula - uses statistical distance measures.


## Source: Barbuti & Ferro 2020 (Mathematics)

### Interdisciplinarity Metric (Co-citation Based)
**Symbol**: XMi
**Type**: Interdisciplinarity
**Formula**: `XMi = (si/(si-1)) × (qi / Σ(rij - 1))`
**Variables**:
- si = number of citations to paper i
- qi = number of duplicated co-citation links (X-motifs)
- rij = number of references in citing paper j
- Summation over all si citing papers

**Notes**: Based on co-citation network structure. XMi measures insertion in specific field. IDRIi = 1 - XMi measures interdisciplinarity. Values in [0,1]. High XMi = paper embedded in coherent field. Low XMi (high IDRI) = interdisciplinary.

### X-Motif Count
**Symbol**: qi
**Type**: Network structure
**Formula**: `ki = Σ(rij - 1) - qi`
**Variables**:
- ki = degree in co-citation network
- rij = references in citing paper j (excluding focal paper)
- qi = number of non-redundant X-motifs

**Notes**: X-motif = pattern where two citing papers share two cited papers (including focal paper i). qi counts duplicated co-citation links.

### Aggregated XM-Metric
**Symbol**: XM{i1,i2,...,in}
**Type**: Interdisciplinarity (set of papers)
**Formula**: `XM{i1,...,in} = (Σsik / (Σsik - n)) × (Σqik / ΣΣ(rikj - 1))`
**Notes**: Mediant-based aggregation. Satisfies mediant inequality: aggregated value lies strictly between individual values.


## Source: Uzzi 2013 (Science)

### Journal Pair Z-Score
**Symbol**: z
**Type**: Novelty/Conventionality
**Formula**: z-score comparing observed vs expected co-citation frequency
**Variables**:
- Observed: frequency journal pair appears in references
- Expected: frequency from randomized citation network

**Notes**: z > 0 = conventional pairing (more common than chance). z < 0 = novel pairing (less common than chance). Generated via Monte Carlo randomization preserving citation distributions.

### Median Conventionality
**Symbol**: median(z)
**Type**: Paper-level conventionality
**Formula**: median of z-scores for all journal pairs in paper's references
**Notes**: >50% of papers have median z > 64. Fewer than 4% have median z < 0. Science relies heavily on conventional combinations.

### Tail Novelty
**Symbol**: 10th percentile(z)
**Type**: Paper-level novelty
**Formula**: 10th percentile of z-score distribution for paper's journal pairs
**Notes**: Captures unusual combinations in left tail. Only 41% of papers have 10th percentile z < 0. High-impact papers: high median conventionality + high tail novelty (10th percentile z < 0).

### Hit Probability
**Statement**: Papers with high median conventionality AND high tail novelty have 2× hit rate
**Formula**: P(hit | high median z, low tail z) ≈ 9.11% vs 5% baseline
**Notes**: "Hit" = top 5% citations. All other combinations (high-high, low-high, low-low) have lower rates.


## Source: Bornmann 2019 (Journal of Informetrics)

### Novelty Score U (Lee/Uzzi variant)
**Symbol**: U or Novelty_U
**Type**: Novelty
**Formula**: `U = -ln(Commonness_10th_percentile)`
where `Commonnessijt = (Nijt · Nt)/(Nit · Njt)`
**Variables**:
- Nijt = number of co-citation pairs from journals i and j in year t
- Nit = number of pairs with journal i in year t
- Nt = total pairs in year t
- 10th percentile taken over paper's journal pairs

**Notes**: Negative log of 10th percentile commonness score. Higher U = more novel. Validated against F1000Prime tags. Standard deviation increase in U → 7.5% increase in "new finding" tag assignments.

### Novelty Score W (Wang variant)
**Symbol**: W
**Type**: Novelty
**Formula**: `W = Σ (1 - cos(Ji, Jj))`
**Variables**:
- Sum over new journal pairs (not co-cited before focal paper)
- cos(Ji, Jj) = cosine similarity of co-citation profiles
- Co-citation profiles from 3 years prior to focal paper

**Notes**: Based on new combinations not previously co-cited. Only counts pairs co-cited at least once in 3 years after publication. Excludes 50% least-cited journals. Validation results mixed - lower convergent validity than U.


## Source: Fontana 2020 (Research Policy)

### Atypicality Score
**Symbol**: AT
**Type**: Novelty/Atypicality
**Formula**: Based on pairwise cosine distances of references
**Notes**: Measures unusualness of combinations. Related to Uzzi's approach but uses cosine distance in reference space. Paper provides empirical validation across multiple disciplines.


## Summary: Diversity Framework Hierarchy

### Order 0 (Variety)
- N0 = n (species richness)
- Sensitive only to presence/absence

### Order 1 (Variety + Balance)
- N1 = exp(H) = exp(-Σ pi ln pi)
- Geometric mean, sensitive to rare species
- Standard in ecology

### Order 2 (Concentration)
- N2 = 1/Σ pi²
- Arithmetic mean, emphasizes common species
- Related to Herfindahl index

### General Order q
- Nq = (Σ pi^q)^(1/(1-q))
- As q increases: more weight on abundant species
- Continuous spectrum of measures

### Key Properties
1. **Monotonicity**: Nq decreases as q increases
2. **Replication**: N identical non-overlapping communities → diversity = N
3. **Evenness**: Ea,b = Na/Nb (ratio of diversity orders)
4. **Partitioning**: Nwithin × Nbetween = Ntotal


## Interdisciplinarity Metrics: Three Approaches

### 1. Category-Based (Rao-Stirling family)
- Uses predefined classification (WoS categories, etc.)
- Formula: Δ = Σ dij pi pj
- Problem: depends on classification choice

### 2. Citation Network-Based (Betweenness, coherence)
- Uses network position
- Formula: β = Σ (gikj/gij)
- Problem: size effects

### 3. Co-citation Based (Barbuti-Ferro)
- No predefined categories
- Formula: IDRI = 1 - XMi
- Advantage: classification-free
- Property: aggregates via mediant


## Novelty vs Conventionality

### Empirical Pattern (Uzzi 2013)
- Science shows high conventionality in median
- Breakthrough work: conventional core + novel tail
- Optimal: 85th-95th percentile median conventionality + tail novelty

### Measurement Approaches
1. **Z-score method** (Uzzi): compare to randomized network
2. **Commonness method** (Lee): probability-based
3. **New combinations** (Wang): first-time pairings
4. **Distance-based** (Fontana): cosine similarity of profiles

### Validation
- Novelty U: validated against expert judgments (F1000Prime)
- Novelty W: weaker validation
- Keyword-based: poor performance
