### Key insight

**Dr. Farid's grant diversity (4 panels) might suggest interdisciplinarity,
but the bibliometric panel + internal collaboration data reveal this is
polymathic breadth, not integration.** The institution can detect this because
it sees co-authorship and co-supervision patterns that external databases
cannot.

**Dr. Emma's moderate bibliometric profile is reinforced by cross-departmental
collaborations and co-supervisions** — genuine integration visible in
institutional processes.

## Data Requirements Summary

| Indicator | Internal data | External data |
|-----------|---------------|---------------|
| Δ (diversity) | Reference categories from repo | Similarity matrix (WoS/Scopus/LLM) |
| S (coherence) | Bibliographic coupling from repo | None |
| E (cross-field) | — | Citation data (OpenAlex/Scopus) |
| Co-authorship diversity | Author affiliations (HR system) | None |
| Co-supervision diversity | PhD records (registry) | None |
| Grant diversity | Grant records (finance system) | None |

**Main obstacle:** E requires external citation data. Institutions without
Scopus/WoS subscriptions can use OpenAlex (free) but face data quality issues.

**Workaround:** A two-component internal panel (Δ, S) + institutional indicators
(CoAuth, CoSup, Grants) provides substantial discriminatory power without
external citation data.
