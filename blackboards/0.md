# Indicator Panel Witness: Diversity, Coherence, Cross-Field Effect

Ref: Porter-Rafols 2009, Rafols-Meyer 2009, Leydesdorff-Rafols 2010

## Definitions

### Rao-Stirling Diversity

\Delta = \sum_{i,j} d_{ij} \, p_i \, p_j = 1 - \sum_{i,j} s_{ij} \, p_i \, p_j

- p_i: proportion of references in category i (derived from publication vectors)
- s_{ij}: cosine similarity between categories i and j
- d_{ij} = 1 - s_{ij}

### Mean Linkage Strength (Coherence)

S = \frac{1}{\binom{n}{2}} \sum_{k < l} \cos(\mathbf{r}_k, \mathbf{r}_l)

- n: number of publications
- r_k: reference vector of publication k over categories
- cos: cosine similarity (bibliographic coupling proxy)

### Cross-Field Effect Proxy

E = \frac{\text{citations received from articles outside publication's primary category}}{\text{total citations received}}

- Primary category of publication k: argmax_i r_{k,i} (ties: lowest index)

## Computation: Rao-Stirling Diversity

### Researcher A

H_A = \sum p_i^2 = 0.09 + 0.005625 + 0.030625 + 0.1225 + 0.01 = 0.258750

Cross terms (×2): 0.090938
\sum s_{ij} p_i p_j = 0.258750 + 2(0.090938) = 0.440625

**\Delta_A = 1 - 0.4406 = 0.559**

### Researcher B

H_B = \sum p_i^2 = 5 × 0.04 = 0.200

Cross terms (×2): 0.110
\sum s_{ij} p_i p_j = 0.200 + 2(0.110) = 0.420

**\Delta_B = 1 - 0.420 = 0.580**

### Researcher C

H_C = \sum p_i^2 = 0.4839

Cross terms (×2): 0.13524
\sum s_{ij} p_i p_j = 0.4839 + 2(0.13524) = 0.7544

**\Delta_C = 1 - 0.7544 = 0.245**

### Diversity Comparison

| Researcher | \Delta | Interpretation |
|------------|--------|----------------|
| A (integrator) | 0.559 | High diversity |
| B (polymath)   | 0.580 | High diversity |
| C (specialist) | 0.245 | Low diversity  |

**Key observation: \Delta_A ≈ \Delta_B (gap 0.021) — diversity alone cannot discriminate.**

## Discrimination Result

**Proposition.** No single scalar from {\Delta, S, E} separates all three types.

- \Delta: A ≈ B (0.559 ≈ 0.580, gap 0.021), fails to discriminate integrator from polymath
- S: A (0.733) and C (0.881) both moderate-to-high, imprecise without \Delta context
- E: B (0.063) and C (0.211) both low, imprecise without S context

**The full triple (\Delta, S, E) uniquely characterizes each type.**
